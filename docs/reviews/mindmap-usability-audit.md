# 思维脑图可用性检查（2026-09-06）

## 结论

基础编辑链路已接通，不能把“有入口”当作“完整可用”。本次复现发现：工具栏原有条件式“中心主题”按钮可提交成功，但空白画布没有创建提示，空图 Enter / Tab 无效；折叠分支下新增主题不可见，画布移开后新节点也可能落在视口外。以上问题已修复。

## 本次修复

- 空白画布显示“新建中心节点”主按钮与操作说明，默认文本为“中心主题”，创建后直接编辑。
- 空图 Enter / Tab 均建立唯一中心节点，删除整图后恢复空态，可撤销、重做、刷新并再次新建。
- 新增及粘贴自动定位；在折叠分支下插入时，以同一 semantic command batch 展开祖先，撤销插入时恢复原折叠状态。
- 搜索可展开折叠祖先并定位结果；画布获得独立定位容器，小地图不再盖在大纲上。
- 粗体、斜体、下划线保留其他已有文字样式，增加可读按钮名称及选中状态。
- 重命名按 Unicode 字符偏移保留原有格式；中文输入法确认不再提前提交；工具栏 Tab 切换不再误建主题。搜索支持 Enter / Shift+Enter / Escape，适配画布按实际视口计算。
- 无变化的主题重命名不再写入历史；根节点右键菜单禁用不成立的“同级主题”；首次加载后正确订阅画布尺寸。
- 所有持久化改变仍经过 mindmap semantic command → 服务端 Artifact transaction → snapshot，没有引入第二套领域模型。

## 2026-09-07 主题与交互优化

对照腾讯文档的主题预览选择方式，加入六套脑图主题卡片。`settings.themeId` 通过已有
`mindmap.setSettings` 事务保存，支持历史恢复；配色和分支继承在视图层派生，显式节点颜色优先。
支持恢复主题配色，颜色面板与画布采用同一套默认值。没有新增 schema 或第二套 Graph engine。

中心节点、一级分支、后续主题具有不同视觉层级；分支连线随主题配色变化。
节点旁快捷加号直接指定父节点；初次打开适配画布；Ctrl/Cmd 滚轮以指针位置为缩放中心，移除平移缩放的延迟动画。
新增主题持久化、撤销重做、显式配色保留与重置、非选中节点快捷新增、指针缩放定位回归。
