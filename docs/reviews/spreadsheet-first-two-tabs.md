## 2026-09-06 续轮：范围格式与实际显示

- canonical `FormatRange` 增加 typed `fields`：每格保留未选定的样式属性；不再以左上格相等作为整区免提交条件。完整样式替换仍用于格式刷这一明确语义。
- `outerBorders` 在引擎中按选区边缘应用，保留内部既有框线；空白内部格不会因为外框命令被无意义地物化。
- 网格消费字号（pt）、字体与垂直对齐；条件格式叠加保留其它显示属性；双线框线使用可显示双线的宽度。
- 文字容器改动后的拖选命中改为 `closest('[data-cell]')`，排序与求和拖选回归通过。
- 格式化单元格再次编辑使用 canonical 原始数值/公式，不把显示结果写回。`SetCell` 保留既有样式；键盘删除和编辑器清空使用 `ClearRange(contents)`，不清掉格式。
- 表格样式使用 typed `rowPattern`（firstRow / alternatingRows）和格式字段批量命令，表头与隔行配色一次撤销，保留数字格式、字号、字体等未选择属性。
- 最终 17 个 Spreadsheet 浏览器用例全部通过，包括表格样式与再次编辑。
- 新增引擎回归：混合样式保留与 undo/redo、外框边缘与内部边保留、未知字段拒绝、相对选区起点的表头/隔行模式。
- 前端类型检查、Vitest 和构建通过（Vitest 输出含 workspace symlink 重复发现，不将显示总数当作独立场景数）。最新 `oo-spreadsheet` 61 个测试与全部 17 个浏览器用例通过；最终 Rust 全工作区测试通过（包含 61 个 Spreadsheet 测试）。

### 仍需处理的已确认限制

- 大于 `MAX_RANGE_MATERIALIZE` 的范围目前只格式化已有格：整列/大选区的空白格与后续输入尚未完整继承格式，需要持久化稀疏范围样式设计，不能当成已完成。
- 目前的顶部/底部/左侧/右侧框线仍逐格应用；需补充选区单边框线语义验收。
- 合并单元格的几何与滚动锚点读取已修复；自动换行与行高仍需继续验收。
- 冻结元数据已持久化，但 Grid 尚未消费 freeze 做固定行列；筛选隐藏行目前保留原坐标空洞。这两项不能仅以按钮激活态认定完成。
- 其余插入页和开始页占位功能按上表保留完整目标。
